# A bug

* **Criteria:** the ticket's `Reproduction:` and `Same fault:` lines. With no confirmed reproduction, get one by the `bug` skill first.
* **Scientific debugging:** test a hypothesis of the cause before editing. Mark the ticket's `Guess:` line held or wrong.
* **Fix the cause** where the wrong value is first produced, never in the caller that reported it.
* **No interface step.** The review's design is the confirmed cause.
